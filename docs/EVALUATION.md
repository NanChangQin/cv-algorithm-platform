# 数据集评测

用带标注的图片衡量算法效果：建立评测集 → 选择算法运行 → 查看指标和最差样本。入口在左侧导航“工作 → 数据集评测”。

## 建立评测集

1. 填写名称，选择任务类型。
2. 上传评测图片（会进入图片库，同一张图不会重复存储）。
3. 选择标注文件。标注按**文件名**和上传的图片对应（忽略目录，大小写不敏感）。创建后会列出标注里找不到图片的文件名、以及没有标注的图片。

| 任务类型 | 支持的标注格式 |
|---|---|
| 目标检测 | COCO JSON（`images` / `annotations` / `categories`，`bbox` 为 `[x, y, 宽, 高]`），或平台 JSON |
| 图像分类 | CSV `文件名,标签`（可以有表头），或平台 JSON |
| 文字识别 | CSV `文件名,文本`，或平台 JSON |
| 图像分割、姿态估计 | 平台 JSON |

平台 JSON 的格式：

```json
{"items": [
  {"file": "a.jpg", "detections": [{"label": "person", "bbox": [10, 20, 110, 220]}]},
  {"file": "b.jpg", "label": "cat"},
  {"file": "c.jpg", "labels": ["road", "car"]},
  {"file": "d.jpg", "text": "京A12345"},
  {"file": "e.jpg", "keypoints": [{"name": "nose", "x": 120, "y": 80}], "threshold": 0.05}
]}
```

平台 JSON 里检测框为 `[x1, y1, x2, y2]`；每项只需要和评测集任务类型对应的字段。

## 运行与指标

每张图片、每个所选算法各创建一个推理任务（一次最多 2000 个），使用算法的默认参数。任务全部结束后报告会被缓存。

| 任务类型 | 指标 |
|---|---|
| 目标检测 | 类别相同且 IoU ≥ 0.5 算正确检出；精确率、召回率、F1 按全部图片累计的正确检出/误检/漏检计算 |
| 图像分类 | Top-1、Top-5 准确率（逐图平均） |
| 图像分割 | 预测类别集合与标注类别集合的精确率、召回率、F1（逐图平均） |
| 文字识别 | 字符准确率 = 1 − 编辑距离 / 标注长度；平均编辑距离 |
| 姿态估计 | PCK：关键点距离小于图片长边 × 阈值（默认 0.05）算正确 |

报告里每个算法列出按主指标从低到高的样本（只列没拿满分的），点开可以直接查看那次推理的结果。失败的推理任务不计入指标，会单独提示数量。
