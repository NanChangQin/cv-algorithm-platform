# 数据集版本与校验

本阶段完成 YOLO 检测数据的导入、三划分、检查、预览与训练来源追溯。独立 test 作业、自定义权重、断点续训与多卡交互属于后续阶段。

## 使用

1. 在训练中心数据集区域填写名称、选择版本归属及划分配置，上传 ZIP。新数据集从 v1 开始；选择已有版本会创建同系列的新版本，原版本不变。
2. 点“详情与预览”查看 train / val / test 的图片、背景和框数，各类别在不同划分的数量，以及错误与重复检查结果。图片可按划分分页，标注框可以开关。
3. 下载原包、规范化包，或完整 JSON 报告。报告包含每图来源路径、内容 SHA256、尺寸、类别与检测框、错误标注、孤立标注、重复组和跨划分泄漏组。
4. 详情页“创建新的划分版本”从原包重新生成数据，不改写旧版本。若图片或标注有更新，在训练中心选择版本归属并上传新包。
5. 用指定版本训练。训练详情显示数据版本、规范化包哈希和划分配置；发布的模型 lineage 也保留同一快照。

## 划分规则

- `preserve`：保留已识别的 train / val / test 目录。没有目录归属的图片加入 train；如果缺少 val，只从 train 按配置的 train:val 比例抽取。已有 test 不会被重命名为 val，也不会丢弃。此模式不会凭 test 比例新建测试集。
- `reshuffle`：明确重新划分全部图片，包括原 test。比例之和必须为 1，train 和 val 必须大于 0，test 可为 0。页面比例单位为百分比，API 为 0～1。
- `seed` 为 0～4294967295 的整数。按原始图片字节的 SHA256 分组，使用 seed 和组哈希的稳定排序分配；相同内容总在同一组。分配优先接近目标图片数，同时保证每个非零划分至少有一组；组大小不同或图片较少时，实际比例会偏离设置值。
- 包内顺序、ZIP 时间戳或外包装目录不影响划分与规范化包哈希。规范化文件顺序和 ZIP 元数据固定。原包哈希反映原始 ZIP 字节，可能不同。
- 按原始图片字节检查完全重复，不检测重新编码、缩放或近似内容。保留原划分时仅报告泄漏，不擅自移动图片；重新划分按组处理。尚未实现按类别分层或视频来源分组。

## 校验与存储

审计修复模式删除无法解析的标注行，保留原包和全部错误报告；严格模式发现错误行或孤立标注即拒绝导入。缺失/空标注按背景图处理，训练集仍必须有有效框。声明类别越界、非法路径、同路径重复（忽略大小写）、损坏图片、超大图片及未规范化 EXIF 旋转始终拒绝。

同一系列版本号在仓储事务内分配；PostgreSQL 使用系列计数器的行锁与唯一约束，删除版本也不复用编号。没有原地更新接口，训练或后续版本引用的数据集禁止删除。

主机 `<storage>/training-store/datasets/` 下每个新版本有三个文件：

| 文件 | 用途 |
| --- | --- |
| `<UUID>.zip` | 固定结构的规范化训练包，包含独立 test（若有） |
| `<UUID>.source.zip` | 原始上传，复现导入和新划分的依据 |
| `<UUID>.index.json` | 图片索引与完整审计报告 |

迁移后的历史数据保留原 ID、哈希和训练引用。没有原包和导入报告时不生成虚假的来源记录；预览通过只读扫描旧规范化包提供。若需派生新版本，先下载规范化包重新上传，并选择旧版本作为父版本。

迁移降级会删除系列、版本号、父版本、原包哈希和划分配置列；这不等于无损回滚。产生新版本后若需回滚部署，应以发布前数据库和文件备份为准。

## API

所有接口沿用会话鉴权、训练角色和项目隔离。

| 接口 | 输入/用途 |
| --- | --- |
| `POST /api/v1/training/datasets` | multipart `file`、`name`、可选 `parent_id`、JSON 字符串 `split_config` |
| `GET /api/v1/training/datasets/{id}` | 版本、系列、父版本、双哈希、配置、统计 |
| `POST /api/v1/training/datasets/{id}/versions` | JSON 划分配置，从保留原包创建版本 |
| `GET /api/v1/training/datasets/{id}/images` | 可选 `split`、`offset>=0`、`limit=1..100`；返回 total/items |
| `GET /api/v1/training/datasets/{id}/images/{image_id}/preview` | 最长边 1280 像素的 JPEG，避免直接暴露压缩包内任意路径 |
| `GET /api/v1/training/datasets/{id}/archive?source=false` | 规范化包；`source=true` 下载原包 |
| `GET /api/v1/training/datasets/{id}/report` | 完整 JSON 校验报告与图片索引 |

配置示例：

```json
{"mode":"reshuffle","train":0.7,"val":0.2,"test":0.1,"seed":42,"validation":"strict"}
```

本阶段的检查边界：单图不超过 4000 万像素；仅支持目录划分约定与 YOLO 检测/多边形标注。独立验证/测试任务及泄漏组交互修复尚未接入。
