# 使用体验与界面优化（2026-10-22 重新设计）

## 主要变化

- 工作台改成单屏：左侧选算法、调参数、选运行位置，右侧上方是图片条，下方直接显示结果。运行后不再跳转，进度和结果都在原地显示；同一张图用过的算法可以从“本图结果”菜单切换查看。多选批量推理时，每张图上有状态点，←/→ 键逐张翻看结果；手机上“运行推理”固定在屏幕底部。
- 任务中心：分页、筛选和搜索交给服务端，一次只读 20 条；状态标签显示各状态数量；每行带缩略图；点一行在右侧抽屉查看结果、参数和执行信息，可直接重试、取消、复用配置。只轮询当前页还在运行的任务。
- 任务详情：结果在第一屏；检测列表在结果区够宽时放在图片旁边，窄时放到下方；输入图片、运行参数（按算法定义的顺序和中文名）、任务信息放在下方卡片。
- 图片库从服务端分页读取，支持按文件名排序（抽帧图片即按帧序）。
- 深色模式：默认跟随系统，也可以在右上角切换浅色/深色；颜色统一改为语义化变量，新增页面不必再写死颜色。
- 导航按“工作 / 资源 / 管理”分组，“资源中心”“算法中心”改名为“图片库”“算法库”；侧栏底部显示当前项目，有多个项目时可以直接切换。

## 验证

- 前端 ESLint、类型检查、39 项交互测试和生产构建通过；新增工作台结果联动、批量状态、任务中心服务端筛选、抽屉、图片条选择和任务跟踪的测试。
- 用内存模式后端加演示数据，在浏览器实测 1440px 桌面（浅色/深色）和 390px 手机布局，控制台无报错。

# 使用体验与界面优化（2026-10-21）

## 主要变化

- 全局：操作结果统一用右下角提示条反馈；页面里没有单独处理的失败操作，也会提示失败原因，不再“点了没反应”。
- 上传：图片支持拖拽、多选和 Ctrl+V 粘贴截图，显示上传进度；每 10 张一批上传，某批被拒时逐张重试，只把不合格的文件单独列出来。
- 缩略图：新增 `GET /assets/{id}/thumbnail`，列表、选择器和历史记录只加载缩略图，不再一次性下载所有原图。
- 工作台：用缩略图选择图片。点击选择一张，勾选右上角圆点可多选，最多 50 张批量推理；遇到限流自动等待重试。选择“自动调度”时不必等服务器列表加载完成；支持 Ctrl+Enter 提交。
- 任务详情：检测结果列表与画布联动，鼠标移到列表行或检测框会互相高亮；类别标签显示数量；显示输入图片、运行中实时计时，以及“对比其他算法”入口。
- 结果对比：按各算法自己的参数默认值提交（原先固定传 `confidence: 0.5`，没有该参数的算法会被拒绝），可以展开调整每个算法的参数；只列出可用算法，不足两个时说明原因；支持全部五类结果，汇总表比较结果数量、主要类别与耗时；新增 `GET /comparisons`，显示最近的对比。
- 算法中心：宽屏时详情固定在右侧，列出运行参数、同一算法的其他版本和镜像信息；启用、停用、回滚、删除都会提示结果和失败原因；算法包支持拖拽上传。
- 资源中心：搜索、排序、全选，选中后可以直接批量推理或打包下载；点击图片打开大图预览，可用方向键翻页。
- 高级编排：按“媒体推理 / 工作流 / 运行节点 / 扩缩容与灰度 / 部署与指标”分页，所有输入框都有标签和说明，运行记录显示中文状态并可跳到对应任务；运行节点可编辑，显示各节点 GPU；部署清单可选择算法并复制。
- 项目、用户、实例、系统页面：角色和状态改为中文，补充确认与失败提示；用户只有改动后才能保存，不能停用当前账号。
- 首次打开平台时，管理员菜单不再缺失；对比详情等子页面的面包屑显示正确。

## 验证

- 前端 ESLint、类型检查、27 项交互/展示测试和生产构建通过。
- Python 回归测试 44 项（Backend）、19 项（Algorithm Manager）、7 项（SDK）、2 项（跨服务协议）通过。
- 用内存模式后端加演示数据，在浏览器实测 1440px 桌面和 390px 手机布局：工作台多选批量、任务详情检测列表联动、资源预览、算法详情、对比构建与结果、高级编排各分页，浏览器控制台无报错。

# 使用体验与界面优化（2026-10-16）

## 主要变化

- 统一浅色界面、图标、表单和按钮，提高常用文字的可读性。
- 桌面使用分组侧栏；窄屏使用折叠菜单，支持 Escape 关闭、键盘焦点循环与页面切换后自动关闭。
- 工作台按算法、图片、参数与资源分区；展示输入预览、服务器/GPU、提交前摘要；支持恢复默认参数和参数边界校验。
- 资源中心和算法中心提供直接开始推理的入口；结果页可复用原任务的算法、图片、参数与请求的执行位置。
- 任务中心展示状态计数，支持按名称/图片/服务器搜索、按服务器筛选、批量选择和下载已完成结果。
- 手机任务列表和运行实例使用卡片，避免为了查看信息横向拖动整张表。
- 结果页突出中文状态、服务器名称、设备、耗时和可视化结果。图像自动适应可用宽度，并可手动缩放、恢复适配和下载。
- 历史任务缺少执行位置时标明未记录，不误显示为仍在等待执行；后台轮询更新列表时不隐藏已有内容。

## 验证

- 前端类型检查、12 项交互/展示测试、生产构建通过。
- Python 回归测试 55 项通过；数据库迁移链保持单一版本头 `20261016_0002`。
- 浏览器实测 1440px 桌面布局与 390px 手机布局，无页面横向溢出；手机结果图自动缩放到可用宽度。
- 浏览器实测菜单打开/导航关闭、服务器筛选、原任务配置复用和远端推理。
- 新任务 `1ac7ee0a-5b7b-4b76-8f38-2a0a98ccc0db` 在 Dell GPU 0 执行完成，返回标准检测结果。
